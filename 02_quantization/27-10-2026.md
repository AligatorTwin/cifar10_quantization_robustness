# 27 Oct 2026

Summary of the quantization study. Notebook is Quantization_FP32_vs_INT8.ipynb.

## About the old one

• The first attempt never made an 8 bit model. Weights stayed float.
• Its data was drawn shapes, not photos.
• Nothing from it could be used.

## What was built

• New notebook. Same pipeline idea, new code.
• Pulls real CIFAR 10 off the internet. 50000 train photos, 10000 test photos.
• Small CNN. 2.34 million weights.
• Trains it in 32 bit.
• Quantizes that same trained model to 8 bit. Real static quantization. Fuse, prepare, calibrate on 512 photos, convert.
• Weights become int8. Activations become int8. Real integer kernels run on the CPU.
• Then quantizes to 4 bit. Weights only. One scale per output channel. Codes packed two per byte.
• Every model shares the same trained weights. No retraining anywhere.
• Every model sees the same test images in the same order.

## What is measured

• Accuracy on 10000 test images.
• Per class accuracy for each model.
• The same 8 test photos through each model.
• File size on disk.
• CPU time per batch of 128 images.
• Agreement between the models.
• Weight histogram, float versus 8 bit.

## Results

• 32 bit : 80.66 percent
• 8 bit : 80.61 percent
• gap : 5 images out of 10000
• Models agree on 98.2 percent of images.
• 70 images went right to wrong. 65 went wrong to right.
• Size : 9.38 MB down to 2.36 MB. About 4 times smaller.
• CPU : 352 ms down to 178 ms per batch of 128. About 2 times faster.
• 8 bit weights use 241 of the 256 possible levels.
• The 4 bit section was added later and has not been run yet.

## What it means

• 8 bit costs almost nothing on this model. Same accuracy, 4 times smaller, 2 times faster.
• 4 bit is where accuracy starts to move. About 8 times smaller than 32 bit.
• Quantization can never raise accuracy. Rounding only throws numbers away.
• Small gaps are noise. 5 images out of 10000 is nothing.
• The 8 bit model is real. Weight dtype is torch.qint8. Layers are quantized classes.
• The 4 bit model stores real 4 bit weights but still computes in float.

## Extra pieces in the notebook

• Bonus sweep. 8, 6, 4, 3, 2 bits. Shows where accuracy breaks down.
• Weight bits versus activation bits. Shows which one costs more.
• Calibration test. The same 8 bit model fed bad calibration images.
• Proof cell. Checks dtype, layer names, int8 value count, file size, CPU only kernels, 4 bit packing.
