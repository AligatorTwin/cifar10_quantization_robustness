# 2 Nov 2026

Summary of the attacks study. Folder is Robustness_Study.

## Why

• Read the RobustMQ paper. It tests quantized models under attacks, bad images and system noise.
• Idea was to run the same three models through the same tests.

## What was built

• New folder. New notebook. Robustness_vs_Quantization.ipynb.
• Same three models as the quantization study. 32 bit, 8 bit, 4 bit.
• Trains the model inside the notebook so it stands alone.

## What gets thrown at the models

• Attacks. FGSM and PGD. Three budgets each. 1/255, 2/255, 4/255.
• Corruptions. 10 kinds, 2 levels. Gaussian noise, shot noise, impulse noise, defocus blur, motion blur, zoom blur, brightness, contrast, pixelate, fog.
• System noise. 4 resize modes. Nearest, bilinear, bicubic, area.
• Perturbations are made once, so every model sees the same inputs.

## Metrics, taken from the paper

• ACC, clean accuracy.
• AR, accuracy under one attack.
• AAI, the relative drop.
• WCAR, accuracy when no attack in the set works.
• mNR, mean accuracy over all corruptions.
• NCI, the relative drop over corruptions.
• SR, spread of accuracy across the resize modes.
• A transfer matrix between models.

## The gradient problem

• Attacks need gradients.
• int8 kernels have no gradients.
• Fix was to attack a float twin. Same shape, carries the dequantized int8 weights.
• The twin agrees with the real 8 bit model on 97 percent of images. Good enough.

## v1 results

• 1000 images.
• It ran on CPU. Model trained on 12000 images for 6 epochs. Clean accuracy 64.2 percent instead of 80.
• 32 bit 64.2. 8 bit 64.1. 4 bit 61.5.
• 8 bit is the same as 32 bit. The gap sits inside the noise.
• Natural robustness matched the paper. 32 bit beats 8 bit beats 4 bit.
• Adversarial robustness did not match. The paper says fewer bits are tougher. We got the opposite.
• Reason. The paper used QAT models. This used PTQ models. QAT is where the attack gain comes from.
• Bug 1. Transfer matrix diagonal printed 0.0. It was never written.
• Bug 2. Bilinear resize scored worse than nearest. That was a grid alignment problem, not a real result.
